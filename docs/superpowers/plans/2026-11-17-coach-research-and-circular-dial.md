# 麻将同分优选审计与圆形庄家盘实施记录

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 核查最新研究、完善同向听同进张优选与默认选牌；将庄家盘改为无叶片圆盘，统一 HUD 字号/贴边位置、居中出牌操作及头像在线状态。

**Architecture:** 复用 Rust 精确向听、Q/K 有界前瞻和公开上下文排序；Godot 接收排名并沿用事件快照驱动的默认选中。三维庄家盘独立修改，不改变规则、网络和桌面布局。

**Tech Stack:** Rust core / GDExtension、Godot 4.7.2、GDScript。

**Spec:** 用户当前明确指令与 `docs/MAHJONG_AI_RESEARCH_20261117.md`。

## 约束与检查重点

- 不读取暗手、真实牌墙或服务器隐藏信息；合法动作以服务端为准。
- 不自动提交推荐牌，不覆盖本窗口玩家手动选择。
- Q/K 是加权搜索指标，不是校准胡率或真实鸡蛋期望值。
- 复用现有隔离验证工程；不重启现网、不修改既有安装包，不限帧。
- 检查模拟第五张、首摸库存消耗、同向听改良、无计算与真零的区别、迟到结果与真实点击。

## 任务

1. **研究核查**：论文原文和作者项目；区分日麻、国标、台湾与贵阳规则。输出研究文档及当前/未来能力边界。
2. **Rust 搜索**：`rust-core/src/coach.rs`、`coach/context.rs`。先复现非法第五张模拟，增加容量守卫；独立逐分支扣库存和后弃牌枚举验证 Q/K；核对 2019 论文同分例。新增 `look_ahead_evaluated`，不改既有排序合同。
3. **桥接与解释**：`rust-gdext/src/lib.rs` 返回 `lookAheadEvaluated`；`mahjong_efficiency_overlay.gd` 显示推荐排名、已计算 Q/K 和判据，避免将未计算显示为零，接炮提示注明最终合法动作权威。沿用既有 `guiyang_3d_screen.gd` 默认选择。
4. **圆形庄家盘**：`mahjong_wind_dial.gd` 移除叶片几何，96 段旋转剖面与平滑法线替换多边形盘体；保留直径、四风/庄家绑定和计时锚点。
5. **验证**：core release tests、Windows 原生桥接构建、coach bridge/state/auto-selection/overlay/double-tap Godot 回归；原生截图核对圆盘、指标详情及四种横屏比例，记录桌面算法基准。分别报告桌面模拟与未执行的移动实机性能/发布。
6. **追加 HUD 要求**：房间号/局数/余牌以同视口旧实际字号为基准增加 3，改金色；Logo、聊天/表情/麦克风组及左右玩家卡距对应安全区边缘 10 屏幕像素，对家居中。检查最终字体拟合、长房号、四种横屏尺寸及触控遮挡。
7. **头像与操作区**：不再创建绿色状态圆点，头像按公开在线状态显示原色或灰色；新快照、失联与重新入座通过事件更新。打出/碰/杠/胡/过集中在手牌上方居中，窄屏分行仍居中，不再寻找两侧空位。检查每席上线/掉线、四种观察方向、观战、旧快照，以及多响应按钮的布局和真实点击。
8. **鸡蛋余额**：数值后显示独立鸡蛋图标，按数字长度预留宽度、整组居中、图标保持比例和输入穿透。检查0/100/9999/八位余额、四种横屏比例及真实原生数字像素。
