# 向听与进张审计（2026-11-16）

本轮仅修改本地牌效辅助。服务端玩法、网络协议、现网进程、已有玩家数据和已冻结的 0.4.13 构建均不改动。

## 定义与持续显示

- `shanten.minimum` 是本桌允许牌型的**结构向听数**：0 为结构听牌，完整和牌为 -1。HUD 计算对象为 13 张等效手牌或 14 张等效手牌打出一张后的状态，因此显示值非负。
- `ukeireCount` 是能降低上述向听的**未见有效牌张数**。按总牌数减自己的暗手与公开实体计数，不等于真实牌墙里还剩多少张，也不是胡牌概率。
- 14 − 3×副露组数：只对服务端 `play` 选项允许的物理牌实例计算“打出此牌后”。重复牌值复用同一牌型分析，但不能放宽服务器的物理牌 ID 限制。
- 13 − 3×副露组数：整手分析，不再假设打一张成 12 张。每张底部标签显示相同的整手基准值；`analysisMode=hand`、`rank=0`，详情明确“当前整手（非打出建议）”，没有单牌推荐。
- 每份公开快照按房局身份、epoch、手牌、副露、弃牌、翻鸡与动作选项刷新缓存。别人出牌也重算。提交动作时不先修改手牌或清空已确认数值；收到服务端新快照再更新。无业务轮询。
- 对手暗杠只接收服务端隐藏占位；不推测其花色。已被碰杠拿走的弃牌按物理 ID 去重；`last_discard`、`ji_events` 的镜像不重复扣除。

## 发现并修正

1. **非自己回合主动清空标签**：原 `_layout_coach` 要求自己的合法出牌动作，否则清空分析并显示“待”。现在区分当前整手与打出候选，持续提供已确认状态的分析。
2. **第五张同牌导致伪听牌**：原面子/搭子/将计数丢失同牌库存约束。例如 `1111m111444p111s` 被算成 0 向听，实际 1 向听。先加入失败测试复现，再改为按花色逐位构造合法目标牌型，动态规划最小缺牌数；每种牌目标数不超过四张。
3. **自己已碰杠的牌必须占用本人的结构库存**：自己碰出的三个 1m 加暗手一个 1m，不可能再以 1m 作暗手单钓将。新增 `own_meld_tiles`，只从结构牌型容量扣除自己已完成的副露；其他人公开牌只影响进张库存，避免把结构向听与知识约束距离混为同一数值。

## 贵阳与其他玩法边界

项目实际 `CanHuHand`（guiyang 2.0.0 / basic_108 1.0.0）允许四面一将或未副露七对，四张同牌按两对计。分析同步这一合同，包含龙七对结构，不套用日麻“七种不同对子”公式。当前服务端没有七对禁用开关；本轮未擅自添加规则或修改番数。

`legalWaits` 仍为 `not_checked`。0 向听不证明已经满足“有杠才能接炮”等胡牌资格；真实胡牌按钮仍以服务端合法动作为准。未知规则或版本不显示猜测值。

## 网络调研的一手材料

- [MahjongRepository 的 shanten 源码](https://mahjongrepository.github.io/mahjong/_modules/mahjong/shanten.html)：确认 3n+1/3n+2 的手数、日麻七对的不同对子约束，以及四枚同牌的特殊处理。其七对定义与本桌不同，不能直接替换。
- [pymahjong 算法说明](https://agony5757.github.io/mahjong/advanced/shanten_calculation.html)及[原始跨花色错误报告](https://github.com/Agony5757/mahjong/issues/30)：局部最优面搭组合不能保证全局最优；`245568m245568p77s` 加入回归，预期 2 向听。
- [xiangting 实现与定义](https://github.com/Apricot-S/xiangting)：最小补牌数比向听数大 1，必要牌指能降低补牌数的牌。作为术语与目标距离定义的交叉参考，本项目未引入其日麻规则依赖。
- [Yan、Li、Li 的论文（2021）](https://arxiv.org/abs/2108.06832)：知识约束的 deficiency 与普通结构距离需要区分。现有 HUD 继续显示结构向听，并独立按公开知识计有效未见牌，不声称已实现论文整套知识约束搜索。

## 追加：本家出牌回合自动优选

玩家进入自己的合法出牌窗口或摸到新实体牌时，依据最新有效原生结果按向听最小、进张最多、Rust 排名、物理牌 ID 稳定排序自动选中一张牌。自动选择只更新选中与高亮，绝不发送出牌命令；点击已选牌或“打出”才进入既有权威命令链。

窗口身份绑定房局、座位、实体手牌、摸牌 ID 和自身副露。手动改选/取消后本窗口不再自动覆盖；公开牌更新、重布局、断线重连不重复选择。响应阶段或他人回合结束旧窗口；重新进入本家合法窗口可再选择。应用结果时另外核对完整状态身份（包含 epoch、phase、turn、规则与可见牌），拒绝迟到分析。原生组件缺失或失败不编造选择。标签显示开关不阻止已请求的自动优选。

`mahjong_auto_selection_smoke` 经失败复现后通过，覆盖合法 ID 限制、原生真实排序、自动不提交、手动优先、同手牌跨响应窗口、新摸牌、延迟结果身份、组件缺失与恢复、重复通知、相同牌值稳定择 ID，以及真实鼠标点击已自动选中牌只提交一次。原有 labels、double_tap、reference_buttons 三项回归同时通过。
