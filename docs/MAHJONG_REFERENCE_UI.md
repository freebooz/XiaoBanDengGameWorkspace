# 贵阳麻将参考界面与按钮逻辑

更新：2026-10-09。当前参考用户最新提供的 `codex-clipboard-f9f8c07b-4aab-4fa0-aaea-dcaf1e9cf74a.png`；此前湖景版已替换。

## 界面

黑色会所背景、黑金三维桌框、翡翠绿提花桌布、方形头像与切角玩家卡片。自己的真实三维手牌直立并略微倾向摄像机；对手暗牌使用同一闭合模型的空白牌面，侧席略微朝内转动以显示绿色牌背，不构造对手私有牌面。

桌面中心为随自身席位转向的八角方位盘，青色数字显示服务器截止时间换算的回合／响应秒数；剩余牌数位于顶部房间栏。选中手牌抬起并显示金色描边和箭头。自己的公开碰杠牌采用左内侧两排，避开直立手牌、弃牌、信息卡及响应按钮，最多容纳四组杠牌。玩家卡片和操作区随实际手牌投影调整位置。

桌与牌继续实时三维渲染，沿用真实导入模型、原桌框 PBR 贴图及金色嵌边。背景、透明标识、圆形响应图集和桌布色图由内置 image_gen 制作；方形头像使用用户参考图的原生 AtlasTexture 区域。资源位于 `client/games/mahjong/guiyang/assets/ui/`，提示词与来源见 `ARTWORK.md`。桌布使用单张完整 UV 覆盖，不依赖重复接缝。

四位房间号、庄家、余牌、分数、在线状态、合法动作和倒计时来自实际状态。自己显示登录昵称；未提供昵称的其他席位显示牌友编号。参考图中的八局赛制、风圈、延迟和金币数没有作为虚构实时数据加入。

## 按钮

| 入口 | 实际行为 |
| --- | --- |
| 吃 | 当前贵阳玩法不允许吃牌，按钮禁用并说明；规则面板明确不含字牌 |
| 碰 | 仅有服务端合法碰选项时启用，提交正式碰操作 |
| 杠 | 合并明杠、暗杠、补杠；多种合法选项时弹出具体牌及杠种选择，使用服务器提供的牌 ID |
| 胡 | 仅有合法胡选项时启用，胡牌与计分由服务端判定 |
| 过 | 仅在可响应的阶段提交过牌，不绕过当前回合 |
| 打出 | 点击真实三维手牌，选中抬起并描边后发送本人实体牌 ID；非法阶段、未选牌、断线均不能出牌 |
| 规则 | 显示真实 108 张贵阳捉鸡规则、首胡结算、流局、杠及鸡分；普通点炮和抢补杠胡须本人已有完成的杠 |
| 设置 | 实际低、中、高渲染质量、音乐和牌声／语音开关，本机持久保存 |
| 退出 | 确认后停止录音及音频、关闭连接、返回大厅；联网牌局继续按服务器十五秒超时托管 |
| 聊天／表情 | 固定内容由服务器校验，同桌广播；消息按房间、席位和 ID 去重，并限制每席每秒一条 |
| 自己的麦克风／按住说话 | 按住开始录制、松开发送，最长五秒；快照刷新保留按钮实例，松手、断线和退出均可靠停止 |
| 对手麦克风 | 本机静音／恢复该席语音，正在播放的该席语音也立即静音 |

当前沿用项目贵阳捉鸡玩法：108 张万筒条，不吃牌、无字牌，首胡响应结算。参考图中的血战文案、字牌、八局场次不属于现有规则，因此没有作为虚假的房间数据显示。

操作成功提交后，打出、碰、杠、胡和过进入等待确认状态；重新选牌或连续点击不能重复提交。服务器新快照、拒绝响应和重新连接解除等待。语音和社交保持独立可用。

训练保留本地三维选牌、打牌和补牌练习；训练聊天、表情明确标记本机显示，联网语音不可用。
