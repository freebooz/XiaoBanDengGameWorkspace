# 小板凳麻将客户端审查记录 · 2026-11-16

## 操作资格与杠牌

客户端原 `_legal_options()` 仅对打出检查回合，碰、杠、胡等直接使用快照选项；它还接受没有具体子类型的 `gang`。这会让错误或过期选项显示为可用按钮。现改为：先要求服务端明确提供选项，再核对阶段、座位、实体牌 ID 与公开牌状态。没有服务端选项时，即使手牌看似可以杠，也不自行增加按钮。

- 明杠：其他玩家最新未被取走的弃牌，自己暗手有三张同牌，且牌墙可补牌；不统计已碰副露。
- 暗杠：自己的出牌阶段、四个不同实体 ID 的同牌、具体候选 ID 仍在手中，且可补牌。
- 补杠：自己的出牌阶段、现有三张碰牌副露与手中第四张匹配，且可补牌。
- 碰：响应阶段、当前未取走的弃牌、暗手至少两张。
- 胡：继续由服务端规则引擎决定，客户端仅核对当前阶段、座位与服务器选项，不新增一套判胡规则。
- 打出只在合法出牌阶段显示；响应阶段保留真实“跳过”。多杠选择绑定接受快照的代次，刷新、断线及重连后旧回调不能提交。

原生 Godot 操作回归 43 组通过，覆盖普通无杠、缺失选项、泛杠别名、错误阶段、错误/小数/重复牌 ID、牌墙为零、结束状态、保存与重连、过期快照、多杠选择，以及合法碰/明杠/暗杠/补杠/胡/过的触控路径。随后加入仅调试构建的事件诊断，44 组 headless 回归通过，诊断字段与敏感信息审查通过。专项证据在 `.tmp/mahjong-soft-lighting-20261116/action-legality-*.log` 和 `action-diagnostic/verification.json`。

服务端 `guiyang` 完整测试独立通过，新增响应契约测试核对提交后选项清空、重复/无资格/错阶段命令拒绝且 checkpoint 不变。未发现合法可达牌局的新服务端杠牌生成错误。日志：`.tmp/kong-source-audit-20261115/reaction-contract-independent-20261116.log`、`guiyang-independent-20261116.log`。

**证据边界：**未取得用户那次错误按钮的完整私有快照。以上是已复现并修复的客户端防御缺口，不宣称它是现网事件的唯一根因。现网只读身份检查见 `live-action-readonly.json`；实际服务未重启，当前源代码不等同于已部署版本。

## 牌效与自动选择

向听算法处理了不可使用第五张同牌的结构约束；自家副露影响结构容量，公开牌影响剩余进张。不同牌数阶段分别提供整手状态或合法弃牌候选，迟到结果不得覆盖当前手牌。每次接受相关牌局变化后重新分析，等待期间保持上次确认值，不显示“待”或伪造数字。

轮到自己时按向听升序、进张降序选择合法候选；只选中、不自动提交。用户手动选牌后本轮不再抢选。底部标签色为 0 绿色、1 黄绿色、2 黄色、3 橙色、4 及以上红色。详细算法研究、独立枚举对照及平台构建边界见 `mahjong-coach-algorithm-audit-20261116.md`。

## 模型、材质与灯光

- 模型基础三轴为高 56、宽 39、厚 28 mm；显示倍率另行记录，不能把放大后的屏幕牌称为世界实物 56 mm。几何与相机记录见 `MAHJONG_56MM_TILE_GEOMETRY.md`。
- 选牌使用原有真实牌体、牌面材质的独立绿黄色发光副本，保留图案；不再用外扩方框。最后弃牌水晶同步绿黄色。
- 桌布底色加深为 `#203d25`。桌框复用用户提供的胡桃木原图 RGB，不加橙色滤色。新纹理无损导入，Godot 验证 409×81、8 级 mipmap；生产 shader 继续沿桌边走向取样。
- 沿用原配准的 4096×2048 PBR 图集，将正确凹向的法线深度提升至 0.72；牌面及牌肩使用相同几何/UV 关系。
- 灯组改为一盏斜上方带阴影主光、南侧无阴影补光与东北无阴影补光；最低档关闭东北补光。移除旧多向强光叠加，加入共享静态柔光环境反射，不捕获动态牌、不启用 SSAO/SSR。
- 三档 MSAA 为 2×/2×/4×，各向异性为 4×/4×/8×，单灯实际阴影分辨率为 512/1024/2048。三维渲染预算增加，同时按真实输出像素限制，避免小窗口无意义超采样。已验证 960 宽窗口与 2880 宽窗口使用不同实际渲染尺寸。

最终灯光与相机证据为 `.tmp/mahjong-soft-lighting-20261116/focus-{16-9,20-9,16-10,4-3}`，三个质量档合计 12 张原生图。最终四比例各 40 个密集布局场景，共 160 个通过；逐张抬牌、四杠、36 张弃牌、触控、结算与桌框内沿贴底检查通过，当前 54 个验证脚本与生产代码规范化一致。汇总为 `dense-gates.json`、`focus-gates.json`、`final-layout-summary.json`、`final-source-manifest.json`。这些是 RTX 4090 上的桌面模拟比例，不代表手机 GPU 性能或真机验收。

图像生成工具已生成新的牌面清晰度候选，但输出分辨率低于原图且轮廓与原法线/遮罩未严格配准，因此**没有替换生产 PBR 图集**。候选与审查在 `SourceAssets/Mahjong/imagegen-clarity-20261116/`。不能把该候选称为已接入运行时的 Image2 纹理。

## 语音

只读检查发现 Windows 默认扬声器总静音，两端游戏会话本身未静音。没有擅自修改系统音量。已修复全零录音假成功、反相双声道抵消、采集启动检查，并增加真实送达及静音/失败提示。

四个隔离原生客户端经真实 WebSocket 转发，三个接收端 AudioServer 均产生有效混音，发送端不自播。输入为合成音，**不代表真人麦克风和扬声器听测通过**。详见 `.tmp/mahjong-voice-audit-20261116/report.md`。
