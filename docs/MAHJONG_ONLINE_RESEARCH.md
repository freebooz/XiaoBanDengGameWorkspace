## 小板凳玩家路径和边界

原生竖屏大厅与等候房采用黑、翠绿、金色，突出玩法选择、主操作、房号和座位状态。横屏共享三维牌桌突出手牌、公共牌区、当前行动者、计时和合法动作。返回大厅时恢复可继续的会话入口。

| 玩家目标 | 正常路径 | 需要验证的边界状态 |
| --- | --- | --- |
| 快速匹配 | 大厅选玩法 → 匹配 → 等候和准备 → 进入横屏牌桌 | 取消与成桌同时发生、重复点击、等待断线、同账号已有房间、切换玩法后收到旧事件、规则版本与队列不匹配。 |
| 好友开房 | 选玩法 → 建房 → 复制四位房号 → 好友输号 → 显示四座、准备和开局条件 → 开局 | 空号、格式错误、房号已失效、满座、已开局、重复进房、成员取消准备或离开、房主离开后的交接或解散、重复开局。客人入房看到的是服务端已锁定的规则。 |
| 断线续局 | 重连后读取会话快照 → 恢复原房、原座与当前回合 → 继续合法操作 | 断线时已超时托管、提交确认丢失、迟到或重复事件、房间已结束、原座不可恢复。核对本人暗手和合法操作随快照恢复。 |
| 人机练习 | 选玩法 → 一人三机器人 → 同一套权威规则与横屏桌 → 完成本局 | 两个预设分别跑通，机器人只执行当前合法动作。退出练习、超时和流局应正常收敛，练习与真人结果标明来源。 |
| 本地摸打练习 | 从练习入口打开既有本地练习，熟悉点牌、摸牌和出牌 | 返回大厅后仍能发起联机或人机练习。入口清楚说明练习范围，结果页以权威对局产生的结果为数据来源。 |
| 查看结果 | 权威结算 → 查看本局四家净分及规则明细 → 返回大厅或发起新对局 | 胡牌、流局、重复结算、重连到已完成的牌局、会话内没有已完成结果。再次开局明确发起新对局。 |

## 实施优先级

1. **权威规则与牌桌一致。** 大厅、匹配、邀请房、续局、人机和结算均使用同一房间规则标识及版本。既有贵阳捉鸡为 `guiyang@2.0.0`，基础 108 张为 `basic_108@1.0.0`，后者无鸡分，点炮胡资格无需先完成杠。详细规则合同和牌例见[多玩法实施计划](superpowers/plans/2026-11-11-mahjong-rulesets.md)。
2. **走通三个原生入口。** 快速匹配、四位房号好友房、一人三机器人练习共享正式牌桌和结算。UI 首次绑定读取完整快照，之后以房间、准备、命令完成、连接及对局事件更新。等待和失败都有明确反馈，过时回调不得覆盖当前会话。
3. **保留练习与结果的真实数据。** 本地摸打用于熟悉交互，人机用于完整地练同规则牌局。结果页读取当前会话已完成的对局，至少可核对玩法、来源、四家净分和结束原因。
4. **按交付范围验收。** 核对竖屏大厅与等候、横屏牌桌、两种预设、四端准备和开局、断线回桌、一人三机器人、本地摸打、当前会话结算。排位、完整逐手牌谱、多局连打与生产认证属于后续范围。实体移动设备独立验收。
