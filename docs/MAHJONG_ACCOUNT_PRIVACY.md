# 麻将游客账号与隐私

大厅「账号与隐私」提供退出登录和删除申请。玩家退出时，服务器撤销当前凭据并关闭使用该凭据的麻将连接。申请删除需要确认停用说明，受理后立即停用游客账号、匿名化展示名、撤销全部会话。客户端清除本地登录资料，显示申请编号和待保留审查状态。

受理状态 `pending_retention_review` 表示关联数据进入保留审查。服务端继续保存依法或按实际渠道需要留存的牌局、复盘及审计关联记录。正式环境需为后续处理接入运营人员、玩家查询或通知方式、适用的保留期限与删除履约流程。

`POST /api/v1/auth/logout` 返回 `204`。`POST /api/v1/auth/delete-request` 返回 `202` 和申请回执。两条路由都使用当前游客的会话，旧凭据失效后不能再次访问会话或建立麻将 WebSocket。隔离 API 回归 `TestMahjongGuestPrivacyClosesLiveSessions` 验证了已有连接即时关闭，以及另一账号和历史记录未受影响。
