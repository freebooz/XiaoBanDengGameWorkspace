# 贵阳捉鸡麻将玩法审查

审查对象为小板凳 Go 规则 `guiyang@2.0.0`、好友房创建、对局和结算界面。调研时间为 2026-11-14。公开资料显示贵阳捉鸡存在多种桌规。小板凳采用已指定的严格先杠桌规，本报告将其与公开产品规则逐项核对。

## 公开规则口径

- 同城游说明，无豆可以自摸，在某些大牌型也可接炮。其另一份公开玩法说明允许一炮多响，并提供黄庄查叫。豆分和支付方区分暗杠、补杠与点杠。[胡牌与结算](https://m.tcy365.com/news/d30722.html) · [豆分](https://m.tcy365.com/news/d35239.html) · [对局和黄庄](https://m.tcy365.com/news/d25942.html)
- 双赢麻将采用独胜，普通接炮需要豆，无豆时允许足够番数的大牌接炮。发布资料中给出了七对、龙七对、大对子、清一色等牌型表，以及金幺鸡和金乌骨鸡的计分。[双赢麻将公开规则](https://doublewin.me/guides/mahjong-gz)
- 多乐开发者公开列出冲锋鸡、责任鸡、摇摆鸡、满堂鸡和多个地区子玩法。这些属于其产品的选择，不能据此假定所有贵阳房间都使用相同番数。[多乐开发者说明](https://app.mi.com/details?id=com.duole.zhuojimjhd.mi)
- 中国团体标准 T/TFMJ 3—2024 将贵州捉鸡列在原始地方麻将规则中。该文件是赛事组织规范，未给出可直接照搬的贵阳捉鸡结算表。[规范 6.1](https://www.ttbz.org.cn/Home/PdfFileStreamGet/c3QsMTE4NDEx)

## 项目对照

| 规则 | 当前代码 | 判定 |
| --- | --- | --- |
| 牌张与基础轮转 | 4 人、108 张万筒条，发 14/13/13/13 后余 55 张，不能吃牌。服务器提供碰、明杠、暗杠、补杠和过。 | 核心一致 |
| 豆豆通行证 | 接炮和开启后的抢补杠胡要求赢家本人已完成任一种杠。无豆可自摸。新贵阳好友房锁定该开关，已有房间保留冻结规则。 | 符合小板凳指定桌规。公开产品的大牌免豆例外未采用。 |
| 胡牌结构与番值 | 识别四组一将及七对。大对子、清一色、龙七对等结构可成胡，但没有各自的番型识别和独立计价。自摸每家付 2，接炮者付 3。 | 基础正确，地方番型与计价未完整实现 |
| 三种豆及补牌 | 三种杠均已实现，有牌可补时才给选项。当前三种杠均由其他三家各付 1，补牌沿用普通摸牌游标。 | 操作可玩，豆分与支付方需定版 |
| 抢杠与优先级 | 胡优先，杠优先于碰。同一响应窗口可多人胡，随后结束本局。抢补杠能取消未完成的补杠，但现按普通点炮种类结算。 | 一炮多响与同城游相符，和独胜版本存在差异。抢杠包赔、杠上花和杠上炮未单列。 |
| 翻鸡、幺鸡、黑八 | 结算翻剩余牌第一张，同花色点数循环加一。幺鸡固定 1，启用时黑八固定 2。翻鸡命中固定鸡时未加倍。 | 基础翻鸡已实现，金鸡未实现 |
| 冲锋鸡、责任鸡、包鸡 | 当前只登记全局第一张符合条件的幺鸡或黑八，冲锋值 2/4。首张被碰或杠时另加 1 定向转分。鸡分统计手牌、副露和未认领弃牌，然后两两结差。 | 结算采用简化公式；首张按哪类计数、责任支付方与听牌资格要按目标桌规明确 |
| 报听、过胡、黄庄 | 无主动报听锁牌、杀报、过胡限制和黄庄查叫；牌墙耗尽直接流局，并保留已记杠分。 | 未覆盖公开产品中出现的这些选项 |
| 庄家与多局 | 现固定座 0 为庄。好友房可同座续局，记录完局数。 | 已支持组桌与续局，换庄、连庄、固定局数累计分待补 |

## 验收顺序

1. 先固定严格先杠版的结算表，明确独胜或多响、三种豆的付款、金鸡、冲锋鸡、责任鸡的逐项叠加及合计。
2. 以新规则版本补齐番型、抢杠包赔和黄庄查叫。每条规则先写四席分差牌例，验证积分和为零，再覆盖回放、结算展示与服务重启后的同版恢复。
3. 报听、过胡限制、包鸡、缺门等按目标桌规加入版本化预设。所有开关在房间准备前明确展示。

本次结论是现有项目已覆盖可联机游玩的贵阳捉鸡核心流程和指定的先杠条件。若以公开产品的完整番型、豆分、鸡分及黄庄流程验收，现有版本仍有明显缺项。
