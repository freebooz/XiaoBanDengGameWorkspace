# 小板凳麻将效果图设计与提示词

全套通过内置 ImageGen 出图。登录、大厅、主牌桌及进牌状态使用客户端现有的 `xbd_mahjong_brand.png` 作为独立品牌图层。产品截图里的玩家、局次与得分使用示例数据。

## 共用视觉

单张高保真中国休闲游戏《小板凳麻将》界面效果图。正投影视图截屏直出，不带设备框、不拼版、无作品集文字。附件只取色彩与 UI 原子部件，不借用任何文案、背景构图或功能。稻穗金确认按钮、奶油米面板、暖原木字体匾、细圆竹节边框、藤结、嫩叶绿在线/选中点、晴空蓝。功能简体字清晰大而规整。宽柔连续高光，精细光洁的游戏美术，没有颗粒或锐化。所有背景为同一个贵州村口乡村聚集地：地面是均匀干净的土黄色夯实泥土，开阔和缓，画面看得到一棵茂盛的大树、树下木长凳和小板凳，背景可远眺白墙黛瓦民居、少量稻田。绝对不要石头、石墙、卵石、石砖、铺石路、石台阶、碎石，所有地面是黄土。构图收敛、安静、让位于 UI。可见牌面仅万筒条，不能用字牌。所有数据是设计示例。无需另造文案、编号、功能、浮水印或品牌 LOGO。

奶油米纸面采用清晰的低对比宣纸纹理。木长凳与板凳说明树下聚集地的用途，主要按钮、标签和关键数据使用稻穗金及深栗色文字。登录、房间和记录采用手机竖屏构图，牌桌及桌上弹窗采用横屏构图。

## 交互

- 登录首页没有连接设置或地址输入。登录由客户端使用固定 HTTPS 网关。本机测试域名为 `api.xbd.freeboozstudio.test`，规划正式域名为 `api.xbd.freeboozstudio.com`。本轮交付是效果图。
- 手牌下的金色标签一一对应可打出的牌。点击标签打开非模态进牌面板，展示假设打出该牌后的向听、进牌总数、牌种和每种剩余张数。标签点击不改变选牌或出牌状态。
- 点击牌面选择手牌。选牌后仍需点击「打出」。点击另一枚金色标签可切换详情，面板可主动关闭，在可出牌状态结束时收起。
- 第 39 张展示九万下的「8 张」标签。四条 ×4、七条 ×4 构成 2 种共 8 张。张数按自己的牌及已公开信息理解为未见张数。
