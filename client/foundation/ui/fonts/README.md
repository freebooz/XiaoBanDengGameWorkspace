# Bundled interface font

Noto Sans CJK SC Bold is the shared interface font for all XiaoBanDeng products.
The original brand artwork is unchanged. The font is bundled so Android and
Windows render the same square, bold Chinese glyphs without system-font fallback.

- Upstream: https://github.com/notofonts/noto-cjk
- Source: https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Bold.otf
